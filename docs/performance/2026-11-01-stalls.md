# Speedway and Circuit Breaker stalls

## Cause

Race radio hides the ticker while a news message is visible. The legacy ticker kept scrolling and measuring its hidden contents. Container and item widths became zero. Its fill loop appended eight quotes and removed one on every simulation step. At 120 steps per second, a news message could add 840 invisible elements per second. Entering Speedway and using Circuit Breaker both display race news.

## Fix

Suspend ticker movement and filling while the container or first item cannot be measured. Resume when visible. Bound every ticker push to 96 elements, retaining recent entries and the separate radio history. The 3D builder asserts its replacement hooks. No gameplay or graphics-effect rules were changed.

## Evidence

The generated-game regression failed before the fix. A one-second hidden-news test grew from 704 to 1,544 elements. The same post-fix test stayed at 11 elements. Another Speedway-specific reproduction grew 508 to 1,348 before the fix. The browser regression now checks both triggers, visible ticker recovery, all-event clearing, rival freeze and intentional slow motion.

| Diagnostic | Before | After |
| --- | ---: | ---: |
| Added elements during one-second hidden-news test | 840 | 0 |
| Speedway warm simulation-step CPU p95 | 1.4 ms | 0.5 ms |
| Circuit Breaker simulation-step CPU p95 | 1.6 ms | 0.3 ms |

CPU samples use the same 1000x700 Chromium/software-WebGL fixture and per-frame step/render sequence. These are host diagnostics, not device FPS measurements. Raw scenario summaries and environment details are in the adjacent JSON file. Render costs varied between runs; no GPU or FPS improvement is claimed. The decisive regression metric is bounded hidden DOM growth.

First-use rendering, per-obstacle feedback layout and particle/disposal bursts were investigated separately. Those workloads were not modified because the hidden ticker was the confirmed shared cause. Future device profiling may identify additional graphics limits.

## Repeat

Run `npm test` and `node tests/stalls.cjs` after building. `npm run profile:stalls` writes scenario JSON and a Chrome CPU profile under the ignored `.work/` directory. Set `PROFILE_TAG` to label a run. Set `PROFILE_HTML` to profile a saved baseline HTML. `PLAYWRIGHT_MODULE` may point to an existing Playwright installation.

An independent source review found no actionable issue in the fix. The earlier 2D editions are unchanged.
